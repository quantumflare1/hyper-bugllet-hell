# Hyper Bugllet Hell

A web-based bullet hell game about bugs

## How to Play

Controls:
- Z to fire
- Arrow keys to move
- Shift to slow down
- Mouse to navigate menus

And that's it!

## Contribution

If you'd like to contribute to the development of Hyper Bugllet Hell (or simply run it on a local server), do the following:

1. Install NodeJS (>22.14.0, I don't know what exactly the minimum version is but that's the version I use)
2. Clone the repository
3. Open a terminal of your choice and run `npm install -D vite`
4. Navigate to the folder you cloned the repository to and run `npx vite`
5. Press O or go to `localhost:8080`
6. Done! (hopefully)

(this is my first time ever writing a contribution guide so if there's issues please say so!)
